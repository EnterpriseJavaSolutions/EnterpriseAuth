# EnterpriseAuth
Enterprise authentication server and administration panel for products. Easily hostable with Vercel. 

## How to deploy
[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/import/project?template=https://github.com/EnterpriseJavaSolutions/EnterpriseAuth)

<br>
    
1. Get/Host a PostgreSQL server. I personally use [Neon](https://neon.com) for my PostgreSQL, which has a free tier that is good enough for most uses.
2. Click the "Deploy" button/badge
3. Name your project and click "Create" (this will take a while, please be patient)
